# SolderST — Прошивка паяльной станции

## Платформа
- **MCU:** STM32F411CEU6 @ 96 МГц (HSE 25 МГц, PLL)
- **Плата:** кастомная PCB (2-канальная станция)
- **Дисплей:** ST7789 320×240 landscape (SPI1 + DMA)

## Периферия
| Интерфейс | Назначение |
|-----------|-----------|
| SPI1 + DMA2 | Дисплей ST7789 320×240 |
| SPI2 | ADS1220 × 2 (RTD паяльника и отсоса) |
| I2C1 | EEPROM (конфиг) |
| TIM3 @ 200 Гц | ПИД + программный ШИМ нагревателей |
| TIM5 @ 100 Гц | Антидребезг кнопок |
| TIM2 @ 2 сек | Подавление DOCK датчика |
| TIM10 @ 30 сек | Таймеры сна |
| EXTI0 | DOCK датчик (вибрация, сброс сна паяльника) |

## Меню
### Сервисное меню (CHORD_LONG)
- **Выход** — выход в рабочий экран
- **PreSleep** — таймаут до полусна (мин)
- **SleepTemp** — температура полусна (°С)
- **Standby** — таймаут до выключения (мин)
- **Expert** — вход по SET2_LONG → экран предупреждения → SET2_LONG

### Expert меню
- **Выход / Сброс** — сброс всех параметров текущего инструмента к дефолтам
- **Kp / Ki / Kd** — коэффициенты ПИД
- **Slope / Bias** — калибровка RTD
- Кнопка **TOOL** переключает инструмент (паяльник/отсос)

## Логика сна (TIM10, тик = 30 сек)
1. `counter = preSleepTimeout × 2` — старт
2. `counter == 0` (1й раз) → `preSleep = true`, T → `sleepTemp`, взвод 2й ступени
3. `counter == 0` (2й раз) → `pwrIsOn = false`, нагреватель выключен
4. Сброс паяльника — DOCK (EXTI0)
5. Сброс отсоса — BTN_VAC передний фронт (main loop)

## ПИД (TIM3, 200 Гц)
- Пересчёт каждые 20 тиков (100 мс)
- Программный ШИМ период 200 тиков (1 сек)
- Коэффициенты в Expert меню, хранятся в EEPROM
- Контроль целостности нагревателя в LOW фазе ШИМ
