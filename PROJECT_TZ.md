# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
# Проект: SolderST_STM_V2 - Паяльная станция на STM32F411

## **1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА**

### **Назначение:**
Портативная паяльная станция с двумя режимами работы:
- Режим паяльника (Soldering Iron)
- Режим вакуумного отсоса (Desoldering)

### **Аппаратная платформа:**
- MCU: STM32F411CEU6
- Дисплей: ST7789 240x240 SPI
- Управление: 6 кнопок + 1 кнопка питания
- Нагреватели: 2 канала (паяльник + отсос)
- Память: EEPROM по I2C
- Датчики: термопары, датчик док-станции

## **2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ**

### **2.1. Режимы работы:**
- **Рабочий режим:** управление температурой нагревателей
- **Режим сна:** пониженная температура при бездействии
- **Сервисный режим:** калибровка и настройка
- **Выключение:** полное отключение питания

### **2.2. Управление температурой:**
- Диапазон: 30-450°C
- 3 пользовательских пресета для каждого режима
- Пошаговое изменение температуры кнопками UP/DN
- Автоповтор при удержании UP/DN
- Длинное нажатие SET для сохранения текущей температуры в пресет

### **2.3. Система кнопок:**
**Кнопки управления (6 шт):**
- SET1, SET2, SET3 - выбор пресетов и сохранение
- UP/DN - изменение температуры
- Tool - переключение режимов (паяльник/отсос)
- VAC_ON - включение/выключение вакуумного насоса

**События кнопок:**
- Короткое нажатие (менее 1 сек)
- Длинное нажатие (более 1 сек)
- Автоповтор (каждые 300 мс при удержании UP/DN)
- Аккорд UP+DN (длинное нажатие обеих)

### **2.4. Система таймеров:**
- **TIM3 (10 мс):** обработка кнопок и антидребезг
- **TIM5 (30 сек):** системные таймеры сна и сохранения
- **TIM2 (2 сек):** таймер док-станции

## **3. ТРЕБОВАНИЯ К ОБРАБОТКЕ КНОПОК**

### **3.1. Архитектура:**
Простая и надежная система без сложных структур:
- Глобальные переменные для счетчиков
- Прямая проверка состояния GPIO
- Конечный автомат для обработки состояний

### **3.2. Временные параметры:**
- **Антидребезг:** 3 подтверждения (DEBOUNCE_COUNT = 3)
- **Длинное нажатие:** LONG_PRESS_TICKS (100 тиков = 1 сек)
- **Автоповтор:** REPEAT_INTERVAL_TICKS (30 тиков = 300 мс)
- **Окно аккорда:** CHORD_WINDOW_TICKS (6 тиков = 60 мс)
- **Отложенное сохранение:** SAVE_DELAY_TICKS (150 тиков = 1.5 сек)

### **3.3. Логика работы:**
1. **Нажатие кнопки:** инкремент счетчика button_timer_ticks
2. **Отпускание кнопки:** сброс счетчика button_timer_ticks = 0
3. **Длинное нажатие:** генерация события при button_timer_ticks >= LONG_PRESS_TICKS
4. **Автоповтор:** генерация каждые REPEAT_INTERVAL_TICKS после длинного нажатия
5. **Отложенное сохранение:** флаг needs_saving + таймер save_delay_timer

## **4. ТРЕБОВАНИЯ К ПОЛЬЗОВАТЕЛЬСКОМУ ИНТЕРФЕЙСУ**

### **4.1. Экран 240x240:**
- Текущая температура (крупно в центре)
- Целевая температура
- 3 пресета (внизу экрана)
- Состояние системы (вверху)
- Индикаторы режима и нагрева

### **4.2. Шрифты:**
- AntiquaB_24 для основных значений
- AntiquaB_18 для статуса и пресетов

### **4.3. Цветовая схема:**
- Черный фон
- Белый/зеленый текст для данных
- Красный для ошибок
- Желтый/оранжевый для предупреждений

## **5. ТРЕБОВАНИЯ К ПАМЯТИ И КОНФИГУРАЦИИ**

### **5.1. EEPROM (I2C):**
- Сохранение всех пользовательских настроек
- Пресеты температур
- PID коэффициенты
- Калибровочные данные
- Таймауты сна
- Флаги функций

### **5.2. Отложенное сохранение:**
- Изменения не сохраняются немедленно
- Активация флага needs_saving при изменении
- Сохранение через 1.5 сек после последнего изменения
- Защита от частых записей в EEPROM

## **6. ТРЕБОВАНИЯ К РЕЖИМАМ РАБОТЫ**

### **6.1. Рабочий режим:**
- Поддержание заданной температуры
- PID-регулирование
- Индикация нагрева
- Защита от перегрева

### **6.2. Режим сна:**
- Срабатывание при бездействии (настраиваемо 1-30 мин)
- Понижение температуры до sleep_temp
- Быстрый выход из сна по нажатию любой кнопки
- Индикация режима сна

### **6.3. Сервисный режим:**
- Калибровка датчиков температуры
- Настройка PID коэффициентов
- Тестирование оборудования
- Сброс на заводские настройки

## **7. ТРЕБОВАНИЯ К БЕЗОПАСНОСТИ**

### **7.1. Аппаратная защита:**
- Контроль перегрева
- Защита от короткого замыкания
- Контроль питания

### **7.2. Программная защита:**
- Валидация диапазонов температур
- Проверка целостности данных EEPROM
- Обработка ошибок датчиков
- Watchdog таймер

## **8. ТРЕБОВАНИЯ К КОДУ**

### **8.1. Стиль:**
- Чистый производственный код
- Минимум комментариев
- Понятные имена переменных
- Структурированная организация файлов

### **8.2. Архитектура:**
- Модульная структура
- Четкое разделение ответственности
- Простые интерфейсы между модулями
- Минимум глобальных переменных

### **8.3. Обработка ошибок:**
- Проверка всех возвращаемых значений
- Graceful degradation при ошибках
- Логирование критических ошибок
- Восстановление после сбоев

## **9. ТРЕБОВАНИЯ К ПРОИЗВОДИТЕЛЬНОСТИ**

### **9.1. Время отклика:**
- Реакция на кнопки: не более 50 мс
- Обновление экрана: не более 100 мс
- Переключение режимов: не более 200 мс

### **9.2. Потребление:**
- Рабочий режим: не более 15Вт
- Режим сна: не более 2Вт
- Выключено: не более 0.1Вт

## **10. ТРЕБОВАНИЯ К ТЕСТИРОВАНИЮ**

### **10.1. Функциональное тестирование:**
- Все кнопки и события
- Все режимы работы
- Переходы между режимами
- Сохранение/загрузка конфигурации

### **10.2. Стрессовое тестирование:**
- Длительная работа в рабочем режиме
- Множественные переключения режимов
- Частые нажатия кнопок
- Прерывания питания

## **11. КРИТЕРИИ ПРИЕМКИ**

### **11.1. Обязательные функции:**
- Все кнопки работают корректно
- Температура поддерживается точно
- Все режимы переключаются
- Конфигурация сохраняется/загружается

### **11.2. Параметры качества:**
- Стабильная работа не менее 8 часов
- Отсутствие зависаний и сбоев
- Корректная обработка ошибок
- Соответствие временным требованиям
