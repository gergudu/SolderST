Кнопки → BUTTONS FSM

FSM следит за коротким/длинным нажатием, аккордами, повтором.

Генерирует ButtonEvent_t.

BUTTONS FSM → Команды

COMMANDS_HandleButtonEvent() получает событие и меняет рабочие флаги/температуру/сервисный режим.

Команды → Состояние

Все изменения хранятся в g_WorkFlags, g_TempSettings, g_MenuCursor и т. д.

Состояние также управляет таймерами сна, пресетами и калибровкой.

Состояние → UI

UI читает состояние и отрисовывает экран.

Меню, температура, пресеты, индикаторы — всё отображается на дисплее.

UI не изменяет состояния напрямую, кроме курсора и режима редактирования (через UI_Navigate, UI_OnClick).
